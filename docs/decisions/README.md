## ADR-0001:生产只交付制品(2026-10-14)

**状态**:已拍板(设计支柱)

生产服务器上只有 docker image(Go 二进制 + 前端 dist + nginx),不存在 `.go` /
`.vue` / `.git`,生产机对代码仓库**只有 GHCR 制品 pull 权限,无仓库读权限**。
威胁模型:防「有仓库或服务器访问权的人拷走源码二次使用」;不防 root 级恶意。
Go 原生二进制使逆向门槛达 GraalVM 同级,不再评估混淆/native-image。

## ADR-0002:后端 Go,弃 Java(2026-10-14)

**状态**:已拍板(两轮评估,用户终选)

初评 Java(Spring Boot 3 + jOOQ,业务生态与招聘池);用户追问 Go 后二轮评估终选
**Go 1.25 + Gin + sqlc/pgx**。收益:单二进制轻量部署、原生二进制保密拉满、
AI/文件/JSON 生态无短板。代价(认账):错误处理噪音散布业务函数、sqlc 不覆盖
动态 SQL(订单筛选回 pgx 手写)、业务系统方向招聘池小于 Java。**不重开语言之争。**
